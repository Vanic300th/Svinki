# Библиотека одежды

Рабочая библиотека находится в `Assets/_Project/Content/Clothing`. Состав игровых предметов задаётся явно в `Settings/ImportPolicy.asset`; импорт нового файла сам по себе не добавляет его в игру.

Основные папки:

- `Models` — подготовленные модели одежды для свиньи по категориям;
- `Generated` — созданные импортёром карточки, материалы, меши и префабы;
- `Templates/Definitions` и `Templates/Models` — первоначальные карточки и модели для инструментов;
- `Compatibility/Definitions` — 34 прежние карточки с сохранёнными идентификаторами;
- `Compatibility/DisplayModels` — две прежние модели, на которые ещё ссылается основная сцена;
- `Materials` и `Textures` — общие материалы и текстуры.

Старые карточки и их имена сохранены для совместимости существующих нарядов и сетевого каталога. Их префабы остаются в `Generated/Pickups` с прежними сетевыми идентификаторами и используют актуальные визуальные модели. Удалять их следует только после отдельной миграции сохранений и проверки оставшихся ссылок.

В `Compatibility/DisplayModels` сохранены `Hoodies/hoodie1/hoodie1.fbx` и `Hats/beanie1/Hat1_Tex.fbx`: они нужны существующим объектам `SampleScene` и сохраняют их внешний вид. Эти модели не входят в автоматический импорт рабочего набора одежды. Остальные исходники прежней библиотеки находятся в `ArtSource/Clothing/LegacyModels` вне импортируемого контента Unity.

Модели `*_worn.fbx` используют 16 костей `Pig_Rig`. Импортёр создаёт объёмный предмет для пола в `Generated/GroundMeshes`, подготовленную надетую модель в `Generated/Wearables` и карточку со ссылкой на неё. Во время подбора кости одежды привязываются к костям конкретной свиньи: рукава и штанины следуют движениям, вся одежда наследует сплющивание персонажа. Обувь уже содержит две стопы; дублировать её не нужно.

Это скиннинг, без физики ткани. В крайних позах поднятых рук у исходных моделей остаются пересечения в области подмышек и пояса. Проверочные изображения и отчёты находятся в `ArtSource/Clothing3D`.

Меню **Svinki → Одежда → Разложить 3D одежду по тайникам** заново расставляет предметы на сохранённой карте вне Play Mode. Оно обновляет NavMesh и сетевые идентификаторы предметов. Резервная копия карты до первой замены находится в `Docs/LevelDesign/Before3DClothing.unity`.

Параметры `Display Center`, `Display Size`, `Display Rotation` задаются в карточке предмета. Подготовленные модели для свиньи используют собственную привязку к костям.

Чтобы добавить новую одежду, положите подготовленную модель `*_worn.fbx` в подходящую категорию `Models`:

- `Hats` — шапки, слот головы;
- `Shirts` — футболки, слот тела;
- `Hoodies` — худи, слот тела;
- `Pants` — джинсы, слот ног;
- `Shoes` — обувь, слот стоп.

Выберите исходные модели в окне Project и выполните **Svinki → Одежда → Добавить выбранные модели в каталог**. Это осознанно включает предметы в рабочий набор. Импортёр создаёт карточки в `Generated/Definitions` и префабы в `Generated/Pickups`, а затем обновляет каталог игрока. Перетащите готовый префаб из `Generated/Pickups` на уровень. В игре предмет подбирается на E. Один слот содержит одну надетую вещь; перед подбором другой вещи этого типа освободите слот.

Для открытия папок используйте меню **Svinki → Одежда → Открыть папки моделей**. **Обновить библиотеку моделей** пересобирает только одобренные предметы. Меню **Создать каталог из правил оценки** однократно создаёт начальную политику из текущего каталога `OutfitRating`; существующая политика при этом сохраняется.

Позицию и размер на персонаже и манекене можно настроить в созданной карточке (`Display Center`, `Display Size`, `Display Rotation`). Модель одежды должна быть подготовлена к своей форме; автоматическая привязка произвольной сетки к костям человека не выполняется.

Для футболок, худи и джинсов в карточке есть `Flutter Strength`: сила колыхания надетой вещи (по умолчанию `0.04`, `0` отключает). Эффект действует на надетой одежде и использует движение игрока плюс лёгкое колыхание в покое. Обувь и шапки остаются жёсткими. Это деформация ткани, а не физика тела персонажа; она не создаёт столкновения ткани с руками или ногами.

Для новых `.fbx` и `.obj` в папках мягкой одежды Unity сам включает `Read/Write` у сетки. Если вы кладёте префаб, ссылающийся на модель из другой папки, включите `Read/Write` в настройках импорта исходной модели — без этого вершины нельзя анимировать.
