# Музыка в лобби: варианты и проверка

24 октября 2026. Проверен существующий тракт ccMixter → UnityWebRequest → AudioSource.

## Что исправлено

Раньше серверный таймер начинал отсчёт до загрузки и декодирования трека. Медленное соединение пропускало начало. Теперь сервер публикует готовность и время старта после подготовки аудио; клиенты подстраиваются под общую временную шкалу. В панели виден статус buffering. Временная ошибка сети, HTTP 408/429/5xx повторяет загрузку один раз.

Проверки в Unity Editor:

- Поиск ccMixter вернул шесть треков; контрольный MP3 загрузился и воспроизводился.
- WAV с искусственной задержкой HTTP 3 секунды: позиция во время загрузки 0, позиция при готовности 0; после старта расхождение часов и AudioSource около 0.01 секунды.
- HTTP 503 на первой попытке: повтор успешно загрузил и запустил трек.
- Изменение сетевого состояния требует одинаковой новой сборки у участников; версия протокола повышена до 27.
- Полноценный тест двух отдельных сетевых клиентов в этой проверке не проводился.

## Как это устроено в Discord

1. **Watch Together.** Встроенный YouTube-плеер, общая очередь, синхронные pause/seek/skip, локальная громкость. Discord прямо указывает, что используется embedded player. Источник: [Discord Watch Together FAQ](https://support-apps.discord.com/hc/en-us/articles/26502500234519-Watch-Together-FAQ).
2. **Spotify Listen Along.** Участники подключают собственные Spotify-аккаунты; для Listen Along нужен Premium. Источники: [Discord](https://support.discord.com/hc/en-us/articles/115003966072-Listening-Along-with-Spotify), [Spotify](https://support.spotify.com/bb/article/discord-and-spotify/).
3. **Голосовой поток, в том числе от бота.** Публичный Voice API принимает Opus, stereo, 48 kHz через отдельное UDP/RTP-соединение с шифрованием. Это транспорт готового звука, источник песен выбирает само приложение/бот. Источник: [официальная документация Discord](https://github.com/discord/discord-api-docs/blob/main/developers/topics/voice-connections.mdx).

Это описание публичных интерфейсов и поведения. Из него нельзя заключить, какую закрытую аудиобиблиотеку Discord использует внутри.

## Что можно выбрать для Project S.V.I.N.

| Вариант | Для чего подходит | Что потребуется |
| --- | --- | --- |
| Unity AudioSource + собственный MP3/OGG-каталог на CDN | Предсказуемая фоновая музыка, общая очередь, звук из джукбокса | Файлы и разрешения на их использование; общий ID трека и серверное время |
| ccMixter | Существующий поиск свободно лицензируемых треков | Сохранять сведения об авторе и лицензии; доступность зависит от сервиса |
| Audius | Дополнительный музыкальный каталог | Проверять доступность конкретного трека; read-only API, ключ для повышенных лимитов — [API](https://docs.audius.co/api/) |
| Jamendo | Ещё один API-каталог | Регистрация приложения и client_id; условия зависят от использования — [API](https://developer.jamendo.com/v3.0/tracks) |
| BASS | Надёжное воспроизведение MP3/OGG и интернет-радио | Нативная интеграция, буферизация и соответствующая лицензия — [BASS](https://www.un4seen.com/bass.html) |
| VLC for Unity / LibVLC | Единый аудио- и видеоплеер с широким набором кодеков | Нативные библиотеки под целевые платформы, более тяжёлая поставка — [официальный проект](https://github.com/videolan/vlc-unity) |
| AVPro Video | Продвинутый видеоплеер для телевизора | Отдельный Unity-плагин под целевые платформы — [документация](https://www.renderheads.com/content/docs/AVProVideo-v3/index.html) |
| Видимый YouTube-плеер с общей очередью | Подход как у Watch Together | Сохранить плеер, брендинг и ограничения встраивания; нельзя выделять аудио и прятать плеер — [правила YouTube](https://developers.google.com/youtube/terms/developer-policies) |

Spotify не является прямой заменой джукбокса: его Developer Policy запрещает создание игр с платформой, а SDK также имеет ограничения на коммерческое использование. Источники: [Developer Policy](https://developer.spotify.com/policy), [Web Playback SDK](https://developer.spotify.com/documentation/web-playback-sdk).

Предложение для игры: оставить исправленный Unity-плеер и небольшой управляемый каталог для фонового звука; телевизор развивать отдельно по модели Watch Together. Если воспроизведение конкретных поддерживаемых файлов продолжит сбоить на целевых устройствах, проверять BASS для аудио либо LibVLC для общего аудио/видеотракта. Замена декодера сама по себе не расширяет доступ к каталогам музыкальных сервисов.
